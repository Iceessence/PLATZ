# PLATZ owner status

The current version, build, benchmark and exact launch location are in [CURRENT_HANDOFF.md](CURRENT_HANDOFF.md). The [Studio guide](START_HERE.md) shows how to launch that executable and continue the same validation workspace.

PLATZ currently supports GPU 3D scene authoring, editable parametric meshes, reusable GLB geometry, base-color overrides, native RGBA pixel sources, and isolated Play. The integrated paint workspace puts the authored source and its live Vulkan consumers side by side. Use the project’s existing image on a UV-mapped slot or create one from the Texture workspace. Apply publishes an undoable project change and Save writes it to disk.

The active release envelope is **A — Authentic foundation**, with early material and asset workflow depth. Independent acceptance is pending. Key gaps include durable transform hierarchy, reusable authored Material assets, direct topology editing, high-end lighting and antialiasing, gameplay logic and export, and original PLATZ AI. The [ledger](DECISIONS_AND_FEATURE_LEDGER.md) maps these to the Master.
